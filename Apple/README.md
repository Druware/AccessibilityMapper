# AccessibilityMapper

This is a simple application built to make it (relatively) easy to create an 
overlay map of an area that provides a visual view of the distances as they 
relate to non-car mobility. Each map is stored as a simple .json file for the 
points of interest. When rendered, these points each get 4 'bullseye' circles. 
The inner circle being the .5 mile radius walking zone. The next out is the 1 
mile radius 'Safe Routes to School'. The third zone is the 2 mile radius bicycle
zone. Finally is the 3 mile radius Low Speed Vehicle ( personal mobility ) zone
that covers e-bikes, scooters, one-wheels, and even where appropriate "golf 
carts".

Any group can be suppressed on display from the check boxes on the left. Each 
marker can be named. Change modes between creating markers and selecting them 
from the left side 'tools' options. The starting point can be found using a zip 
codeor city and state. 

## Goals and Intent

Doing advocacy work, and often finding a need to present just how much of an 
area needs sidewalks, bike lanes and/or multi-use paths, it was incredibly 
tedious to build out visual maps using traditional tools. This project fills 
that need, where it can rapidly build out those maps. 

In the long term, there are some ideas to add, including ways to merge several
maps into one, as well as an iPad version, and possibly a version for the 
Vision Pro.
